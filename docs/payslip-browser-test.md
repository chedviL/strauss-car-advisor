# בדיקה ידנית בדפדפן — זרימת תלוש → חילוץ → אישור → השוואה

מדריך קצר לבדיקה שלך בדפדפן. השרת והלוגיקה אומתו בבדיקת אינטגרציה ללא מודל
(tests/integration/pg-payslip-flow.test.ts). כאן בודקים את החוויה בפועל ואת
החילוץ האמיתי (Gemini, במכסה החינמית).

## מצב אימות (לפני שתתחילי)
- אומת בצד השרת (ללא דפדפן, ללא מודל): העלאה → חילוץ מדומה → שחזור חילוץ ממתין →
  אישור (אידמפוטנטי, null אינו אפס) → זיהוי חוסר → השלמה → השוואה → שחזור אחרי רענון.
- **עדיין ממתין לאימות**: (1) **חילוץ אמיתי** עם Gemini מתוך קובץ אמיתי;
  (2) **הורדת הקובץ הבינארי** מ-Supabase Storage (נחסמה ע"י NetFree — ראו
  docs/supabase-setup.md). אל תסיקי שהסבב המלא עובד עד ששניהם אומתו.

## דרישות סביבה
- `.env.local`: `DATABASE_URL` (Postgres), `MODEL_API_KEY2` (Gemini), `CHAT_FAST_PATH=0`.
- לאחסון התלוש: או `SUPABASE_URL`+`SUPABASE_SERVICE_ROLE_KEY` (אחסון פרטי אמיתי),
  או `STRAUSS_ALLOW_FILE_STORE=1` לפיתוח מקומי. *אל תגדירי שתי האופציות יחד אם
  ההורדה חסומה ב-NetFree* — להעלאה+חילוץ אפשר להישאר עם Supabase; לקריאת הקובץ
  המלאה (אם חסום) עדיף `STRAUSS_ALLOW_FILE_STORE=1` עד פתיחת החסימה.
- הרצה: `npm run dev` (אל תריצי `npm run build` במקביל).

## קבצים לבדיקה
`tests/fixtures/payslips/payslip-1.pdf` (שכבת טקסט), `-scan-clear.png`, `-scan-degraded.jpg`.

## שלבי הבדיקה
1. פתחי את האפליקציה (http://localhost:3000). פתחי שיחה חדשה.
2. בתיבת ההקלדה, לחצי על אייקון המצורף (או גררי קובץ לתוך התיבה) והעלי
   `payslip-1.pdf`. ודאי:
   - ההיסטוריה מציגה "📎 הועלה מסמך: payslip-1.pdf" (שם בלבד, לא תוכן).
   - מופיע חיווי שהחילוץ משתמש במודל ומחכה לאישורך.
3. אשרי חילוץ. (קריאת Gemini אחת, במכסה החינמית.) אמור להופיע כרטיס אישור עם:
   - שכר בסיס, פנסיה %, קרן השתלמות %, נקודות זיכוי — עם הערך שחולץ.
   - עמלות/בונוס שלא הופיעו בתלוש — ריקים (לא 0), מסומנים כחוסר/ודאות נמוכה.
   - הבחנה בין שכר בסיס לבין ברוטו כולל/בסיס מס/נטו.
4. בכרטיס: תקני במידת הצורך, ואשרי. ודאי:
   - השדות הוחלו על "הפרטים שלי".
   - שדה שהיה ריק (עמלות/בונוס) נשאר לא-ידוע — לא נדרס לאפס.
5. המשיכי את הבקשה בשיחה (למשל: "השוואה מקורולה קרוס ל-ATTO 3"). אם חסרים
   עמלות/בונוס לחישוב — היועץ ישאל; עני (למשל "אין עמלות ואין בונוס"). ודאי
   שההשוואה מתבצעת רק אחרי השלמת החוסר, ושלא נשאלת שוב על נתון שכבר נמסר.
6. **שחזור אחרי רענון**: רעונני את הדף (F5). ודאי:
   - אם לא אישרת עדיין — כרטיס החילוץ הממתין חוזר.
   - אם אישרת וחושבה השוואה — הפרטים וכרטיס ההשוואה מוצגים כפי שהיו.
7. חזרי על 2–3 עם `-scan-clear.png` ו-`-scan-degraded.jpg` כדי לבדוק OCR אמיתי.

## מה לדווח
- צילומי מסך של: כרטיס האישור, כרטיס ההשוואה, ומצב אחרי רענון.
- אם החילוץ נכשל/מכסת Gemini מוצתה — דווחי; אין מעבר אוטומטי לספק בתשלום.
- אם הורדת הקובץ נכשלת עם עמוד NetFree — זה האימות שעדיין חסום; ציין זאת.
