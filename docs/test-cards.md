## נקודות בדיקה חוצות-פרופילים

| תרחיש | מה לבדוק |
|--------|----------|
| "אני מקבל 18,500" | הבוט שואל ברוטו/נטו לפני שמירה |
| "יש לי BYD Atto 3" | הבוט מחפש לפי שם → מזהה CAR-10, קבוצה ג, לא מנחש |
| "BYD Dolphin" | מזוהה כ-CAR-03, קבוצה א, שווי שימוש 2,590 — לא מתבלבל עם Atto 3 |
| עובד קבוצה א מבקש Atto 3 | הבוט מדווח "לא זכאי לקבוצה ג" עם הסבר |
| "15000 בלי" אחרי שאלת שכר | הבוט ממשיך את ההשוואה שהתבקשה — לא שואל שוב מה המטרה |
| "מה אם קרן ההשתלמות 7.5%?" | מוצג כ"לפי הנחה", לא כעדכון עובדה |
| "תלוש יעזור?" | הבוט מסביר שאין העלאת קבצים + מכוון לשורות בתלוש |
| שיחה חדשה אחרי שיחה קיימת | תיק מתאפס, אין נתונים מהשיחה הקודמת |
