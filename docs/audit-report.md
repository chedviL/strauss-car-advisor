## 4. זמנים לכל תור (מדידות שרת בלבד)

כל הזמנים הם **צד שרת** — מרגע קבלת הבקשה עד האירוע. **אינם זמן הופעה בדפדפן** (ראו §ביצועים).

שלבים ותלותם:
- **טעינת מצב** (`stateLoadMs`): לפני קריאת המודל. חציון **391ms** (טווח 378–624).
- **קריאות מודל/כלים**: 1–4 קריאות מודל לתור (חציון 2). תור עם השוואה = 3–4 קריאות (הבנה→כלי→ניסוח).
- **TTFT שרת** (זמן עד אירוע הטקסט הראשון): דומיננטי — thinking ב-medium.
- **זמן עד תוצאת השוואה** (`cardMs`): נמדד כשתוצאת `compareScenarios` מוכנה. בריצה זו רוב ההשוואות הסתיימו בתוך אותה קריאת-כלי; הכרטיס בפועל נשמר בסוף התור.
- **זמן שמירה** (`saveMs`): **אחרי** הזרמת הטקסט (חופף לתפיסת המשתמש, לא מתווסף ל-TTFT). חציון **548ms**.
- **זמן כולל** (`totalMs`): סוף התור.

**שלבים חופפים (לא לחבר כרצף):** הטקסט מוזרם *לפני* השמירה; השמירה (~548ms) אינה מתווספת ל-TTFT. טעינת המצב קודמת לקריאת המודל (כן רציפה).
